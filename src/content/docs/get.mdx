Biryar runs on your own computer. Installing it is downloading two small
files and starting one container; there is no account to make with us,
and nothing you enter ever reaches a server of ours.

## Install

You need [Docker](https://docs.docker.com/get-docker/). Any machine that
runs it will do: a laptop, a small always-on computer at home, a Raspberry
Pi, a Mac with an Apple chip.

<Steps>

1. Make a folder, download the one file Docker needs, and start it:

   ```bash
   mkdir biryar && cd biryar
   curl -fsSLO https://biryar.ciyalabs.com/get/docker-compose.yml
   docker compose up -d
   ```

   Or save [docker-compose.yml](/get/docker-compose.yml) by hand and run
   the last line in its folder. On Windows, in PowerShell, write
   `curl.exe` instead of `curl`, and make sure Docker Desktop is running. The first start takes a minute: it pulls
   the image, prepares the database, and makes the key that seals your
   Amazon credentials.

2. Open [localhost:8000](http://localhost:8000) and choose **Sign up**. The page asks for
   the install's setup code, which the server printed when it started:

   ```bash
   docker compose logs api | grep -A 3 "setup code"
   ```

   (PowerShell: `docker compose logs api | Select-String "setup code" -Context 0,3`.)

3. Back up the sealing key somewhere that is not this machine. Biryar made
   it for you on the first start; this prints it:

   ```bash
   docker compose exec api cat /keys/sealing-key
   ```

</Steps>

Everything else happens in the product: connecting Amazon, adding a Keepa
key, inviting the people you work with. Nothing is typed into a file. The
[install guide](/setup/install/) has the details, and the optional settings
(the port, a pinned version) are in [env.example](/get/env.example).
Updating later is `docker compose pull && docker compose up -d`.

## Try Pro free

Every install can try Pro for fourteen days, once, with no card: under
**Settings, Plan**, choose **Try Pro free**. When it ends, the free plan
carries on with everything you have.

## Buy a licence

**€29 a month, or €290 a year.** One licence covers one business, with as
many people in it as you like.

A licence is one line of text. You paste it under **Settings, Plan**, and
Biryar checks it there, on your machine, by its signature. Nothing is sent
anywhere to check it, so a laptop without a connection keeps working and a
server of ours being down can never switch your repricer off.

**How it goes.** Write to
[info@ciyalabs.com](mailto:info@ciyalabs.com?subject=Biryar%20Pro%20licence&body=Business%20name%20(as%20it%20should%20appear%20on%20the%20invoice)%3A%0AInvoice%20address%3A%0AA%20month%20or%20a%20year%3A%0A)
with three things: the name of your business as it should appear on the
invoice, the invoice address, and whether you want a month or a year. You
get an invoice by email, payable by bank transfer within 14 days. The
licence goes out by email as soon as the payment arrives, and the term
starts that day.

**Renewing** is the same email. About two weeks before a licence ends,
Biryar tells you on its Home page and we write to you; a renewed licence
starts the day the old one ends, however early it is paid, and nothing is
deleted in between. If you let it end, the free plan carries on with
everything you have.
