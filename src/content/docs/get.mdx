## What you need

A computer that stays on while Biryar should work: a Windows PC, a Mac, a
Linux machine, a Raspberry Pi 4 or 5 (64-bit, 4 GB or more), or a small
rented server. About **1 GB of disk, 300 MB of memory, two processor
cores**. **No graphics card**, no second machine, no account with us. An
internet connection, because it reads Amazon and your retailers.

## Step 1: install Docker

Docker is a free program that runs Biryar in a sealed box, so Biryar
brings everything it needs and leaves the rest of your computer alone. It
has to be installed, and running, before the lines in step 2 can work.

<Tabs syncKey="os">
  <TabItem label="Linux and Mac">

  **Mac:** download [Docker Desktop for Mac](https://docs.docker.com/desktop/setup/install/mac-install/),
  open the file, drag Docker into Applications, and start it.

  **Linux:** install Docker Engine, which includes the `compose` part
  Biryar uses. Docker has a page of steps for each system:

  - [Ubuntu](https://docs.docker.com/engine/install/ubuntu/)
  - [Debian](https://docs.docker.com/engine/install/debian/), which is
    also the page for a Raspberry Pi with the 64-bit system
  - [Fedora](https://docs.docker.com/engine/install/fedora/)
  - [Every other Linux](https://docs.docker.com/engine/install/)

  To check, open a terminal and type:

  ```bash
  docker --version
  ```

  A version number means Docker is ready.

  </TabItem>
  <TabItem label="Windows">

  1. Open Docker's page, [Install Docker Desktop on Windows](https://docs.docker.com/desktop/setup/install/windows-install/),
     press its download button, and run the installer it gives you. Leave
     **Use WSL 2 instead of Hyper-V** ticked.
  2. If Windows asks to restart, restart.
  3. Open **Docker Desktop** from the Start menu. It does not start by
     itself the first time. Accept its terms; it is free for a business
     with fewer than 250 people. You can skip making a Docker account.
  4. Wait until Docker Desktop says its engine is running.
  5. Open a **new** PowerShell window (press the Windows key, type
     `PowerShell`, press Enter) and type:

     ```powershell
     docker --version
     ```

     A version number means Docker is ready. A window that was open
     before Docker was installed does not know about it yet, which is why
     it has to be a new one.

  If PowerShell answers that `docker` "is not recognized", see
  [Support](/support/#windows-says-docker-is-not-recognized).

  </TabItem>
</Tabs>

Docker changes how it is installed from time to time. The
[install guide](/setup/install/#dockers-own-instructions-for-each-kind-of-computer)
links Docker's own page for each kind of computer, including Ubuntu,
Debian, Fedora and the Raspberry Pi. Where their page and the steps here
disagree, theirs is right.

## Step 2: start Biryar

<Tabs syncKey="os">
  <TabItem label="Linux and Mac">

  In a terminal (on a Mac, press Command and Space, type `Terminal`,
  press Enter):

  ```bash
  mkdir biryar && cd biryar
  curl -fsSLO https://biryar.ciyalabs.com/get/docker-compose.yml
  docker compose up -d
  ```

  </TabItem>
  <TabItem label="Windows">

  In PowerShell (press the Windows key, type `PowerShell`, press Enter),
  with Docker Desktop running. It is `curl.exe`, not `curl`: PowerShell's
  own `curl` is a different command.

  ```powershell
  mkdir biryar; cd biryar
  curl.exe -fsSLO https://biryar.ciyalabs.com/get/docker-compose.yml
  docker compose up -d
  ```

  </TabItem>
</Tabs>

Or save [docker-compose.yml](/get/docker-compose.yml) by hand and run the
last line in its folder. The first start takes a minute: Biryar is
downloaded, its database is set up, and the key that locks your Amazon
keys is made.

## Step 3: sign up, and save your key

<Steps>

1. Open [localhost:8000](http://localhost:8000) and choose **Sign up**. The page asks for
   the install's setup code. To see it, paste this line into the same
   terminal and press Enter. It is the same on every system, and there is
   nothing in it to change:

   ```
   docker exec biryar-api-1 python -m biryar.init --setup-code
   ```

   It answers `Setup code:` followed by the code. Type that code into the
   sign-up page, then choose a username and a password.

2. Back up the sealing key somewhere that is not this machine. Biryar made
   it for you on the first start; this prints it, on every system:

   ```bash
   docker compose exec api cat /keys/sealing-key
   ```

</Steps>

Everything else happens inside Biryar, on its own screens:
[connecting Amazon](/setup/sp-api/), adding a [Keepa](/setup/keepa/) or
[ScraperAPI](/setup/scraperapi/) key, inviting the people you work with.
Nothing more is typed into a terminal or a file. The
[install guide](/setup/install/) has the details, including backing up
and updating, which is `docker compose pull && docker compose up -d`.

## Try Pro free

Every install can try Pro for fourteen days, once, with no card: under
**Settings, Plan**, choose **Try Pro free**. When it ends, the free plan
carries on with everything you have.

## Buy a licence

**€29 a month, or €290 a year.** One licence covers one business, with as
many people in it as you like.

A licence is one line of text. You paste it under **Settings, Plan**, and
Biryar checks it there, on your machine, by its signature. Nothing is sent
anywhere to check it, so a laptop without a connection keeps working and a
server of ours being down can never switch your repricer off.

**How it goes.** Write to
[info@ciyalabs.com](mailto:info@ciyalabs.com?subject=Biryar%20Pro%20licence&body=Business%20name%20(as%20it%20should%20appear%20on%20the%20invoice)%3A%0AInvoice%20address%3A%0AA%20month%20or%20a%20year%3A%0A)
with three things: the name of your business as it should appear on the
invoice, the invoice address, and whether you want a month or a year. You
get an invoice by email, payable by bank transfer within 14 days. The
licence goes out by email as soon as the payment arrives, and the term
starts that day.

**Renewing** is the same email. About two weeks before a licence ends,
Biryar tells you on its Home page and we write to you; a renewed licence
starts the day the old one ends, however early it is paid, and nothing is
deleted in between. If you let it end, the free plan carries on with
everything you have.
