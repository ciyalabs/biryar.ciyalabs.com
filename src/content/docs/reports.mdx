---
title: Reports
description: Long-form technical writing on how each part of Biryar works.
---

Six longer pieces about how each part works and why it was built that
way. They are readable without any code, and they go into more depth than
the guides do. For how to use Biryar today, start with
[Sourcing](/guide/sourcing/), [Repricing](/guide/repricing/) and
[Portfolio](/guide/portfolio/).

The reports describe the system Biryar is built from, which does more than
Biryar does yet. Reimbursements, writing to manufacturers and brand
ungating are in the reports and not in the product. They are published
anyway, so you can see where it is going.

| Report | Subject |
| --- | --- |
| [Sourcing](/reports/sourcing/) | Harvest, watchlist, screening, the Deals page, and the markdown classifier |
| [Portfolio](/reports/portfolio/) | Landed cost, measured fees, and profit per unit |
| [Repricing](/reports/repricing/) | The envelope policy, the Buy Box model, and price floors |
| [Reimbursements](/reports/reimbursements/) | FBA reconciliation and drafted cases |
| [Upstream](/reports/manufacturers/) | Finding manufacturers worth writing to |
| [Ungating](/reports/ungating/) | Brand applications and wholesale qualification |

Each report opens in its own page, with inline citations that show the full
reference on hover.
